# Panneerselvam A - Portfolio

Responsive Java Full Stack Developer portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Update before publishing

1. Replace `your-email@example.com` in `src/App.jsx` with your real email.
2. Update project descriptions or add real GitHub repository links.
3. Add a resume PDF to `public/` and add a Download Resume button if needed.

## Included

- Responsive desktop/mobile navigation
- Hero section
- About section
- Skills section
- Projects section
- Experience section
- Contact section
- GitHub and LinkedIn links
